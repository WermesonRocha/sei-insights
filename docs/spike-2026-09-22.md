### Unidade Geradora (Unit)
- **Visible field**: `#txtUnidade` ( `<input class="infraText form-control infraAutoCompletar">` )
- **Hidden ID field**: `#hdnIdUnidade` ( `<input type="hidden">` )
- **Autocomplete widget**: `infraAjaxAutoCompletar('hdnIdUnidade', 'txtUnidade', 'md_pesq_controlador_ajax_externo.php?acao_ajax_externo=unidade_auto_completar_todas&id_orgao_acesso_externo=7')`
- **PrepararExecucao callback** sends selected organ IDs:
  ```js
  function() {
    var orgaosSelecionados = obterOrgaosSelecionados();
    if (orgaosSelecionados == null) {
      return 'palavras_pesquisa=' + document.getElementById('txtUnidade').value;
    } else {
      return 'palavras_pesquisa=' + document.getElementById('txtUnidade').value + '&id_orgao=' + orgaosSelecionados;
    }
  }
  ```
- **Target unit**: `MMULHERES-SE-SGA-CGATI-CTI-DTI` (exact label; ID resolved via autocomplete)
- **Request parameters**: `txtUnidade=<label>&hdnIdUnidade=<id>`

### Pesquisar em (Search scope checkboxes)

| `chkSinDocumentosGerados` | `G` | Documentos Gerados | unchecked |

### Date Range

- **Request parameter**: Solr range query in `partialfields`:
  ```

  ```

### CAPTCHA
- **Field**: `#txtInfraCaptcha` (visible), `#hdnInfraCaptcha` (hidden, value `0`)
- **Image**: `/infra_js/infra_gerar_captcha.php?r=s&c=<hash>&i=PESQUISA_PUBLICA<timestamp>`
- **Constraint**: **Never bypass** — only public links exposed by the page itself.

## Step 2: AJAX Response (Search)

### Endpoint
```
POST https://colaboragov.sei.gov.br/sei/modulos/pesquisa/md_pesq_controlador_ajax_externo.php
  ?acao_ajax_externo=protocolo_pesquisar
  &id_orgao_acesso_externo=7
  &isPaginacao=true
  &inicio=0
  &rowsSolr=50
```

### Request Headers
- `Content-Type: application/x-www-form-urlencoded; charset=UTF-8`
- `X-Requested-With: XMLHttpRequest`

### Request Body (form-urlencoded, key fields)
```
txtProtocoloPesquisa=&q=&chkSinProcessos=P&chkSinDocumentosGerados=G&chkSinDocumentosRecebidos=R
&txtParticipante=&hdnIdParticipante=&selOrgaoPesquisa%5B%5D=11&txtUnidade=MMULHERES-SE-SGA-CGATI-CTI-DTI
&hdnIdUnidade=<resolved-id>&selTipoProcedimentoPesquisa=&selSeriePesquisa=&txtDataInicio=15%2F09%2F2026
&txtDataFim=22%2F09%2F2026&txtInfraCaptcha=&hdnInfraCaptcha=0&hdnFlagPesquisa=1
&partialfields=sta_prot%3AP%3BG%3BR+AND+id_orgao_ger%3A11+AND+(dta_ger%3A[2026-09-15T00:00:00Z+TO+2026-09-22T00:00:00Z]...)
```

### Response
- **Content-Type**: `application/json`
- **Shape**: `{ "html": "<table id=\"pesquisaResultado\">...</table>" }`
- **On CAPTCHA failure**: `{ "html": "" }` (empty string)
- **Success**: `html` contains a `<table id="pesquisaResultado">` with result rows.

### Result Row Structure (inferred from SEI conventions & JS)
Each row (`<tr>`) in `#pesquisaResultado`:
- Has `data-prot` attribute with the process protocol number
- Contains a link to `md_pesq_processo_exibir.php?acao_externa=protocolo_pesquisar&id_orgao_acesso_externo=7&id_processo=<id>`
- Columns: protocol number, type, subject, organ, unit, date, status, actions

### Unit Filter Effectiveness
The unit autocomplete **does filter by selected organ** (sends `id_orgao=11` in autocomplete request). The search request includes `hdnIdUnidade` with the resolved unit ID, so the server **does narrow results to the selected unit** when provided.

## Step 3: Pagination & Per-Page CAPTCHA

### Pagination Parameters
| Param | Meaning | Page 1 | Page 2 | Page N |
|-------|---------|--------|--------|--------|
| `isPaginacao` | Enables pagination | `true` | `true` | `true` |
| `inicio` | Offset (0-based) | `0` | `50` | `(N-1)*50` |
| `rowsSolr` | Page size | `50` | `50` | `50` |

### CAPTCHA on Pagination
- **New CAPTCHA per page**: Yes — each paginated request requires a fresh CAPTCHA (`txtInfraCaptcha`).
- **Result termination**: When `html` returns empty or fewer than 50 rows, or when total `itens` (from Solr) is reached. The JSON response does **not** include a total count field; only `html` is returned.

## Step 4: Public Process Page & Document Tree

### Process View Page
- **URL**: `md_pesq_processo_exibir.php?acao_externa=protocolo_pesquisar&id_orgao_acesso_externo=7&id_processo=<id>`
- **Access**: Public (no CAPTCHA) for processes returned by the public search.

### Document Tree (`md_pesq_documento_consulta_externa.php`)
- **URL**: `md_pesq_documento_consulta_externa.php?acao_externa=documento_consultar&id_orgao_acesso_externo=7&id_documento=<id>`
- **DOM Structure** (inferred from SEI standards):
  - Table rows (`<tr>`) for each document in the process
  - Columns: Série (series name), Número (document number), Data (date), Tipo, Assunto, Link
  - **Link**: `<a href="md_pesq_documento_consulta_externa.php?...">` — label **contains the document number** (needed for node→URL correlation)
  - **Text format**: `Nº <documento> / <ano>` (e.g., `Nº 12345 / 2026`)

> **Note**: Could not fetch a live process/document page due to CAPTCHA blocking search results. Structure inferred from SEI 4.1.5 conventions and JavaScript (`sistema.js`) meta-tag mappings (`mt` array maps `prot_pesq`→`txtProtocoloPesquisa`, `id_serie`→`selSeriePesquisa`, `numero`→`txtNumeroDocumentoPesquisa`, etc.).
